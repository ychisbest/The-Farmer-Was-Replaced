Встроенного редактора хватает, но длинные скрипты удобнее писать в **VS Code**. Игра поддерживает это официально (страница **External Editor** во внутриигровой документации).

## Как это работает

- Каждое окно кода сохраняется как **файл `.py`** в папке сохранения.
- В каждом сохранении есть **`__builtins__.py`** с функциями игры — для автодополнения.
- Язык игры **похож на Python**, но это не полноценный Python.
- **Строки `import` игра игнорирует** — они нужны только редактору.

## Шаги

1. В игре **Load → Open Folder**. В Windows обычно `C:\Users\<вы>\AppData\LocalLow\TheFarmerWasReplaced\TheFarmerWasReplaced\Saves\<сохранение>`.
2. В VS Code **Файл → Открыть папку**, выберите эту папку и установите расширение **Python**.
3. В **Options** игры включите **File Watcher**.

## Новые файлы

File Watcher подхватывает только изменения существующих файлов. Создайте файл сначала в игре или перезагрузите сохранение через Load. **Не** нажимайте Save перед Load — файлы, созданные снаружи, могут пропасть.

## FAQ

**Можно ли использовать VS Code?** Да: откройте папку сохранения и включите File Watcher.

**Почему новый файл не появился?** Создайте его в игре или перезагрузите сохранение.
